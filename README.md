# SEO Starter Lab

## About This Project
SEO Starter Lab is a student learning project created to understand and practice the fundamentals of Search Engine Optimization (SEO).

## What I Learned
- Keyword research and search intent
- On-page SEO, including title tags, meta descriptions, headings, and image alt text
- Internal linking and content optimization
- Off-page SEO and backlink building

## Practical SEO Website
I created a beginner-friendly SEO guide to apply these concepts in practice.

**Read the guide here:** [https://seostarterlabs.blogspot.com/](https://seostarterlabs.blogspot.com/) 

## Project Purpose
This project documents my practical learning of SEO techniques as part of my digital marketing training.
